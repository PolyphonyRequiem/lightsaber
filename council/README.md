# Council Minutes

A record of formal convenings of the council. Each file captures the question put to the council and each member's response, preserved verbatim.

The council members live as persona agents in `~/.copilot/agents/council-*.agent.md`. They can be consulted individually at any time. These minutes record the moments when the full body was convened and the chorus was heard.

Files are dated and slug-named in the order they happened. The earliest is `2026-05-01-where-to-start.md`.
