# Experiments

Half-forged ideas. Prototypes. Things that glow but don't yet cut.

This is the workshop. Stuff lands here when it's worth trying but not yet worth committing to the structure of the repo. If an experiment matures into something real, it graduates out. If it doesn't, it stays here as a record of a path explored.

Metaphor names are welcome here. If a thing wants to be called `kyber-crystal/` or `cortical-jack/` because the name is load-bearing, let it.

Currently empty. First passes welcome.
